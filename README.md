# prima-pr-demo

Un piccolo progetto di prova per imparare il flusso di una Pull Request su GitHub.

## Cosa fa

`greet.py` contiene due funzioni di utilità:

- `greet(name)` — restituisce un saluto personalizzato.
- `shout(text)` — restituisce il testo in maiuscolo con un punto esclamativo.

## Test

```bash
pytest test_greet.py
```
